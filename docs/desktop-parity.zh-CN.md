# 旧版设计对照 · Desktop 0.4.2

基准：0.3.1 Legacy Web；目标：Windows DeepSeek Harness Desktop 0.1.7-rc.2。

| 原设计项目 | 桌面版结果 |
| --- | --- |
| 浅蓝灰配色、三种预设与强调色 | 保留，强调色选中圈已补回 |
| 中间助手头像与名称 | 0.4.1 已补回；窄窗口保留紧凑头像 |
| 用户气泡、对话宽度、间距和页头 | 0.4.2 补回；用户手动调整的原生内容宽度优先 |
| 输入框圆角、阴影与发送按钮 | 0.4.2 补回 |
| 侧栏新会话按钮与工作区分隔线 | 0.4.2 补回；折叠时沿用原生标题栏按钮 |
| 莫宁身份卡与顶栏 | 保留；身份卡随原生侧栏尺寸动画更新，折叠时隐藏、展开后恢复 |
| 外观面板、透明度、重置、保存 | 保留；选项仅保存在本地 |
| 运行／工具／完成／错误状态 | 0.4.2 恢复原生可见状态投影，并区分主动停止；历史状态不覆盖新一轮 |
| 轨道扫光、声纹及静止模式 | 保留；0.4.2 补全静止模式对顶栏状态环的处理 |
| 运行耗时与工具耗时 | 运行耗时改接桌面过程栏；工具耗时只读取可见的原生统计弹窗，无数据时为“—” |
| 最近三条消息、时间与发言者标记 | 时间和用户节点标记已补回 |
| 当前已加载正文搜索、定位与高亮 | 保留；补回空结果提示，长回复定位到开头；排除不可见文字与完整 URL |
| 深色模式与插件卸载 | 恢复原生布局与配色；HTML 根节点切换深色也覆盖 |

桌面版保留原生 DeepSeek 品牌、账号入口、Windows 标题栏、折叠和拖动行为。莫宁标识显示在独立顶栏与身份卡中。原生右侧面板打开时优先显示；较窄窗口隐藏观测栏，继续保留对话头像与外观入口。

原来的 Web 服务探测改为 `DESKTOP / LOCAL`，不额外联网，也不据此推断模型连接。无法从当前页面可靠读取的信息不编造数值或状态。

验证采用合成对话的浏览器回归和隔离 profile 的官方运行时加载。0.4.1 的对话头像已在本机界面目视确认；0.4.2 已安装，更新后的本机窗口目视检查因桌面操作中止而未完成。运行／工具／错误等状态由合成原生 DOM 信号验证，未为测试发送模型请求。发布截图只使用合成内容。
